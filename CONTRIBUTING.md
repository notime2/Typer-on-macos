# Contributing

Thank you for your interest in Typer On.

## This project does not accept pull requests

Typer On is developed and maintained by a single author. Product direction,
architecture, and scope are decided by the author alone, and the project is
intentionally closed to outside code contributions.

**Pull requests are automatically closed without review.** This is not a
judgement of your work - it is the project's operating model. Please do not
invest time in preparing a patch for this repository.

## What is welcome

- **Bug reports.** Open an [issue](https://github.com/notime2/Typer-on-macos/issues)
  with your macOS version, the app version, the source application where the
  problem occurred, and steps to reproduce it. Bug reports are genuinely
  useful and are read.
- **Feature ideas.** Open an issue and describe the problem you are trying to
  solve. There is no guarantee it will be built, and no timeline is offered.
- **Security reports.** See [SECURITY.md](SECURITY.md). Do not use public
  issues for security problems.
